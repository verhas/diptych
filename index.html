Diptych is a free, open-source file manager for macOS — two panes, a keyboard that does the work, an AI agent that sees what you see and asks before it touches anything, a whole tree in one filtered list, an editor that knows JSON, XML and YAML, your file servers, and a genuinely useful way to compare two files or two whole folders.

AI agent

Your AI agent sees what you see

At the bottom of every window there is an agent terminal: Claude Code, Codex, Copilot — whichever agent you use — already connected to Diptych through MCP, the Model Context Protocol. It knows what you have selected, what each pane shows, what a comparison found. And it changes nothing behind your back: every change it wants is a list you review first.

⌄

~/.diptych/agentic $ claude

> Which of the selected files is the largest?

⏺ diptych · get_selection

manual.pdf — the largest of the four files you selected.

> Tag the 2025 invoices in the other pane Red, and remove the quarantine from the PDFs I selected.

⏺ diptych · propose_file_operations

The review window is open in Diptych: 15 operations, each one shown with what it has now and what it will have. Untick anything you don't want, then Execute.

An example conversation. The agent asked Diptych — it was never told a file name.

  • ✓ One click to start Click the strip at the bottom of the window, or press ⌃`. Your agent starts, already configured: Diptych writes its .mcp.json and an AGENTS.md that tells it to work on your files only through Diptych.
  • ✓ It sees what you see The selection, the folder in each pane, the open windows, what a folder comparison found — renamed files included. Things a shell has no way to know.
  • ✓ It acts in the window you are looking at It selects files, opens comparisons and Info windows, switches a pane, changes a setting — visibly, in Diptych.
  • ✓ It proposes, you decide Moves, copies, renames, permissions, owners, links, extended attributes, Finder tags, quarantine removal: a review window lists every operation, each one editable and untickable. Overwriting or deleting needs its own tick. And all of it can be undone.
  • ✓ Local, locked, logged Diptych's MCP server listens on this Mac only, answers only with its token, and logs every call where you can see it. Off until you switch it on. Diptych sends nothing anywhere; your agent talks to its own provider, as it always does.
  • ✓ Any MCP agent, anywhere Use the built-in terminal, or File ▸ Add Diptych to Agent Config to connect the agent you already run in your own terminal or editor.

Flat view

A whole tree in one list, filtered by a query language

⇧⌘F turns a pane into one list of a folder and everything under it, filtered by an expression much like find's — but readable, completed as you type, and warned about when it can never match. The rows are ordinary rows: copy, move, rename, trash, or Rename Many all of them at once.

~/Movies — flat
size > 500MB and (name = "*.mov", format = "mp4") and taken between [2024-06, 2024-08]

taken — the date the video was taken, compared as modified is

What it can ask

Names and paths

name = "*.txt", name ~ /^IMG_\d+/i, path != "*/.git/*" — shell patterns or regular expressions, and != or !~ for not.

Sizes and dates

size > 10MB, modified < 2025-01-01, created = 2024-07 for the whole month, size between (1MB, 10MB].

Folders, files and links

directory traversed to walk without listing, directory listed for the opposite; link broken, link loop, link and directory.

Permissions and owners

access = "rwx***---", place by place; owner = "peter", group ~ /staff/, xattr("com.apple.quarantine").

What is inside

contains "TODO", or line by line as grep: contains ~ /FIXME|XXX/. Binary files are never searched for text by chance.

Pictures and videos

camera = "*iPhone*", iso >= 1600, city = "Budapest", near(47.49, 19.04, 5km), duration > 10min — from the header, never the pixels, and never sent anywhere.

Written like this

Comments go between /* and */, anywhere in an expression and over several lines — which is also the quick way to switch part of one off for a run without deleting it.

/* walk everywhere, list only text files mentioning TODO */ directory traversed, file and contains ~ /TODO|FIXME/ /* only into folders named src, and the Swift files there */ (directory and name = "src") or (file and name = "*.swift") /* photos that say where they were taken, from one summer */ image and located and taken between [2024-06, 2024-08] /* links that lead nowhere, outside .git */ link broken and path != "*/.git/*"
  • ✓ Completed on ⌃Space What can come next — a test, a unit, a format, the cameras the last walk found, ISO values and f-stops — and a calendar where a date goes.
  • ✓ Mistakes said as you type Red under what does not parse, with the reason; orange under what parses but can never match — size > 10MB and size < 1MB.
  • ✓ Saved by name, used by name Save images once, then write images and size > 1MB. Every version is kept, and Undo takes a save back.
  • ✓ Holds still while you work Rows arrive as they are found; Stop keeps what was found. Renaming changes one row, and the expression turns brown when the list is stale.
  • ✓ Back where you were Open a folder from the list, and Back returns to the walk at once, the folder you came from selected. Each pane remembers its last six walks.
  • ✓ The same language elsewhere A script's apply-to: header is an expression of it, asked of each selected file — file and name = "*.jpg", image and located.

Text Edit

Edit the text, or edit the structure

Text Edit keeps what you type exactly as you typed it — quotes stay straight, two hyphens stay two hyphens — and saves the file with the line endings and encoding it came with. JSON, XML, YAML, TOML and property lists are coloured, paired, folded, checked and formatted, and shown as a tree in which you edit the structure while the text stays yours.

The tree

  • ✓ Edited in place Double-click a key or value; what you type is quoted and escaped as the format needs. Comments, CDATA and long values get a text area, line breaks and all.
  • ✓ Added, moved, retyped Add Child ⌃⌘N, Add After ⌘↩, Duplicate, Change Type, Delete; drag a node, or ⇧⌘↑ ⇧⌘↓ it through the structure.
  • ✓ The text stays yours Every change is a change in the text, touching only that node and its separators — comments and layout stay, and Undo is the text's.
  • ✓ Element or attribute, by a name Put @ before an element's name and <name>Diptych</name> becomes name="Diptych" on its parent; take it away to go back.
  • ✓ Paths for your tools Copy XPath, JSON Path, yq's YAML path, or PlistBuddy's key path for the clicked node. ⌘F finds in names and values, folded or not.
  • ✓ Property lists, binary too A .plist opens as its tree of String, Integer, Real, Boolean, Date, Data, Dictionary and Array; a binary one is shown as XML and saved as binary — or converted.

The text

<catalog>
  <book id="bk102">
    <author>Ralls, Kim</author>
  • ✓ XML typed along What the markup still needs — >, ="", -->, the innermost open element's end tag — shown in grey and taken with ⌃Space. Closing a start tag puts in its end tag.
  • ✓ Says where it breaks Not valid JSON — line 12, column 5: a comma or } is expected, with Show to go there. JSON and TOML fully checked, XML for well-formedness, YAML for the usual mistakes.
  • ✓ Coloured, paired, folded Keys, strings, numbers, tags and attributes in colour; brackets and quotes close themselves; the structure folds by its chevrons; the matching bracket or tag is marked.
  • ✓ Lines, as IntelliJ does them ⇧⌘↑ ⇧⌘↓ move lines, ⌘⌫ deletes them, ⌘C with nothing selected copies the line, ⌘/ comments it, ⌘G goes to one.
  • ✓ Format Document ⌥⌘L lays JSON and XML out by your indentation — keys in their order, numbers as written, mixed content and xml:space="preserve" untouched. An invalid file is left alone.
  • ✓ A gutter that knows git What changed since the last commit, as IntelliJ shows it, and since the last save; line numbers absolute, relative or off. Structure emphasis shades the block you are in.

File servers

Your NAS, in a pane

Go ▸ Connect to Server… (⌘K) mounts a share and opens it in the active pane. Signing in is macOS's own window, with your Keychain — Diptych never sees a password. Star a server and it stays in the sidebar, a click away.

AddressServer
smb://nas/photos, or just nas/photosWindows shares, most NAS boxes, Azure Files
nfs://host/export/pathNFS, Google Cloud Filestore
https://dav.example.com/remote.php/davWebDAV: Nextcloud, ownCloud, many NAS boxes
ftp://hostFTP, which macOS mounts read-only
afp://old-mac/shareAFP, for old Macs and Time Capsules
  • ✓ Found on your network The sheet lists starred and recent servers, and the NAS boxes and Macs that announce themselves by Bonjour — looked for only while it is open.
  • ✓ Comes back by itself A pane left on a server connects it again at startup and after the Mac wakes. One whose server was ejected waits, and offers Connect or Go Home.
  • ✓ Changes from other machines show up A pane on a server looks again every five seconds while Diptych is in front — or as often as Settings says; 0 leaves it to Refresh.
  • ✓ Slow servers stay usable A folder listed before opens at once, then refreshes; a new one counts as it is read. Picture columns fill in after the rows, and git colours stay off.
  • ✓ Read-only, said plainly On a read-only share what would change it is greyed out, a drop says why it was refused, and the editors say it is the volume that is read-only, not the file.
  • ✓ Saves that are checked A WebDAV refusal when the file is closed is reported, not lost; Bin Edit reads back what it wrote. Volumes in the sidebar show their size and free space.

SFTP and S3 cannot be mounted by macOS itself; mounted with Mountain Duck, rclone or sshfs, they are folders like any other.

Scripts and programs

Your shell scripts as menu commands, executed safely

Put a script in ~/.diptych/scripts, say in its header what it applies to, and it appears in the right-click menu for the files it suits. Diptych is strict about what it executes, because the danger is a script that arrived by mail, not the one you wrote.

#!/bin/sh # name: Make a zip of these # description: Puts what is selected into untitled.zip, beside it. # apply-to: path != "*/.git/*" # args: 1, # only-under: ~/Documents # call: $0 $@

Or start with the ones that come with Diptych: File ▸ Get Scripts… installs them from inside the app, signed with it — read each one first with Show Source.

Executed safely

  • ✓ Nothing quarantined A file macOS has marked with com.apple.quarantine — one that came from a browser, mail or a chat — is refused.
  • ✓ Yours, and read-only A script must belong to you and be writable by no one, you included, so an approved script cannot change afterwards: r--------.
  • ✓ Approved, and approved again You approve a script before its first run and whenever its contents change, by a hash. Every rule is checked again at the moment it runs.
  • ✓ Every name is one argument The call line is split into words before anything is put in, and no shell reads it: my notes (draft).txt arrives whole.
  • ✓ Read when Diptych starts The scripts folder is read once, so what you approved is what runs. Developer mode adds a menu item to read it again while you write one.
  • ✓ Off until you switch it on Scripts are a setting, off by default. Mistakes in a header are reported with the file and the line, not left as a missing menu item.

Running programs

  • ✓ Run with Arguments… ⌥↩ on any executable: arguments and environment variables, the exact command shown first, the earlier runs a ↑ away, and templates you keep.
  • ✓ A real terminal for each run Tabs of one Runs window — colours, progress bars, questions — with Stop, Run Again, Copy Output, the exit status and the time it took.
  • ✓ Downloaded programs are asked about macOS checks downloaded apps; nobody checks downloaded scripts. Diptych asks before one with quarantine runs.
  • ✓ No agent can run anything Running is never offered over MCP — but an agent can read a run's output, so “why did that fail?” needs no copying.

Everyday driving

Everything a file manager should have had all along

Built for people who move, rename, and inspect files all day, and would rather not reach for the mouse to do it.

⇥

Two panes, one keyboard

Tab switches panes, F5/F6 copy or move to the other side, ⇧⌘↑/⇧⌘↓ put files in an order of your own, and every command lives in the menus too, for the days F-keys are busy dimming your screen.

↺

Undo and Redo, for real

Reverses copies, moves, renames, permission and owner changes — across the whole session, fifty steps deep — and asks first when undoing would put something in the Trash.

✎

Rename Many

One regular expression over a folder, the selection, or everything a flat view found, with every new name shown before anything happens. Nothing is renamed until all of it can be — no half-finished batch left to sort out by hand.

◐

Version tracking

Runs the git already on your Mac — nothing bundled, nothing linked — and colours names by what sending your work would actually do. Off until you switch it on.

▤

Bin Edit

A hex editor for the files that aren’t text at all, built in — and it reads back what it saved, so a server that quietly dropped the change cannot fool you.

⌖

An EXIF editor

Dates, camera, description and location on a map — paste a place from Google Maps — for many pictures at once, and an erase that Undo takes back.

◩

Pictures, fixed in place

Rotate and flip without losing quality, convert and resize, remove the location, cut out the subject, read the text in it — with Vision, on this Mac, never sent anywhere.

⌂

Instead of Finder, if you like

Other apps' Show in Finder can open the folder in Diptych, the file selected — one setting, and one to undo it.

⇉

Copies you can watch

A panel with the file, the bytes and an estimate, a Cancel that really stops — and a queue that lists what is waiting, by name, with a time for all of it.

Compare

Compare files, bytes, or whole folders

Two text files get a real line-by-line diff. Two of anything else get an honest byte-by-byte answer. And two whole folders get a window of their own — every file paired up, colour-coded, with a legend so nobody has to memorise the letters.

Two folders

  • ✓ Matched by name, or by content A renamed file is still recognised by its bytes, not left looking unrelated to the one it used to be — and a whole cluster of duplicates says so, not just the one pair.
  • ✓ Colour-coded, at a glance Small letter badges say exactly what differs — name, size, content, permissions, xattrs, ACL, dates, ownership — with a legend so nobody has to memorise them.
  • ✓ You choose what counts as “different” Content always matters; permissions, attributes, ACL, dates and ownership are checkboxes, on the window and as a default in Settings.
  • ✓ Filter, drill in, jump back Search the list, open a subfolder’s own comparison, or send a pair straight back to the panes it came from — ⌘G and it’s selected, ready to act on.

Two files

  • ✓ Lines aligned as a reader would A rewritten line is one changed line, not a deletion and an addition; the words that changed are marked within it; a run of changes is one difference to jump to.
  • ✓ Edit one side, safely A padlock on each side, and only one opens. One press takes a whole difference from the other side; saving keeps the line endings, encoding, permissions and attributes.
  • ✓ Find, only what differs, ignore spacing And wrapping on both sides or neither. The window watches both files and reloads when either changes.
  • ✓ Anything else, byte by byte Two files that are not text get a straight answer: identical, different from the first byte, the same for the first N bytes — in decimal and hex — or one the beginning of the other.

Information

Everything about a file, in one window

⌘I opens an Info window for the file: what the file system keeps about it, what the file says about itself, and who has it open — each tab applied on its own, and every refusal said out loud.

General

Rename in place, the kind and size, and the created and modified dates — editable, not just shown.

Permissions and ACL

Owner and group pickers, the nine bits and setuid, setgid and sticky with the octal mode, and the access control list as ls -le writes it.

Extended attributes

Every attribute xattr shows — text values edited in place, binary ones shown as hex and removable, quarantine included.

Tags and folder icons

Finder tags with their colours, and a folder's custom icon shown, set or taken away.

Details

What the file says about itself: EXIF and GPS with a map link, PDF pages and permissions, a film's tracks and codecs, and what Spotlight knows.

Open By

Which programs have the file open — or, for a folder, anything inside it, or stand in it — which is what stops it being moved.

A change the file will not take is reported, then offered with a brief unlock and relock, then with your password.

Why another file manager

Because your agent should work where you do

Diptych is built around an AI agent that sees your panes, works through the same operations you do, and changes nothing you have not reviewed.

01

The agent sees what you see

Not a chat window beside your files: the selection, both panes, what a comparison or a flat view found. “These”, “the other side” and “the ones that differ” mean what they mean to you.

02

It proposes, you decide

Moves, renames, permissions, tags: the agent hands over a list, you review it, untick what you don't want, and run it. Undo takes back what it did, as it takes back what you did.

03

Workflows in a sentence

Rename photos by the date they were taken, sort invoices into folders by year, find what is in one tree and not the other — asked in words, not hunted for in menus no file manager could have enough of.

04

A Swiss pocket knife of a file manager

Around the agent, the tools you would otherwise open five apps for: a query language for whole trees, an editor for structured files, folder comparison, file servers, scripts — made in Switzerland.

And the basics, as they should be everywhere: free and open source, native, signed and notarized by Apple, no telemetry, no account.
