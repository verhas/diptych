# Diptych 2.0.1

A picture or a text dragged into a pane becomes a file there, even when it
is not a file to begin with: an image out of Photos or Safari, a Mail
attachment, or an entry of a clipboard manager.

---

## Dropping what is not a file

- A drop that carries no file now makes one where it lands: in the pane's
  folder, or in the folder under the pointer. Before, such a drop was refused.
- A file the other app writes when it is dropped keeps the name and format
  that app gives it. When the folder already has a file of that name, the new
  one is numbered.
- A picture or a text with no file behind it is saved as **New from
  Clipboard** saves it: a picture in the format chosen in Settings, text with
  the extension Apple Intelligence suggests, and the name suggested the same
  way. With *Save a picture as* set to **Off**, a dropped picture is saved as
  PNG.
- **Edit ▸ Undo** takes the new file away again.
- As with files, nothing can be dropped into a flat view or a read-only
  folder, and Diptych says so.
